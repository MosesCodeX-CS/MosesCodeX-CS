## 🏗️ What I'm Building

**🫁 OPMAS-001** - Oxygen Plant Monitoring System for Kijabe Hospital
- Read-only Modbus TCP monitoring built on Laravel 12 + Python/pymodbus
- MySQL backend, Supervisor-managed processes, Nginx serving it all
- Because when it's oxygen supply, "probably fine" isn't good enough

**🏠 NyumbaFind** - Kenya-focused rental marketplace
- Laravel + PostgreSQL backend with Sanctum auth and Africa's Talking phone OTP
- M-Pesa Daraja integration for payments, Cloudinary for media
- Landing page, auth flow, and tenant dashboard live; agent dashboard in progress
- Design system built on Emerald, Dark Slate, and Amber

**📱 Bingwa** - Android app automating Safaricom bundle sales via USSD
- Flutter/Kotlin, deep in accessibility services and background service reliability
- Chased down wakelock races, alarm storms, and Doze-throttled callbacks so it doesn't randomly die mid-transaction

**🌐 IT Services & Freelance Work** - Showing the world I can make things look good too, one client project at a time
